# Blustone Server 1.1.0

This release expands persistent hunter management and social interactions, and adds equipment and Gem workflows for explicitly supplied data. Existing saves remain compatible. The default resource profile remains Episode 6 with 139 packages; use the resource ZIP attached here and preserve your existing state file when upgrading. Use Node.js 22 with support for JSON.rawJSON to preserve exact Gem identifiers.

## Added

- Local-account friend discovery, search, requests, acceptance, cancellation, rejection, removal, blocking and persistent Likes.
- Bulk hunter rank-up: combine four rank-1 hunters into a rank-2 hunter, or five rank-2 hunters into a rank-3 hunter, subject to ownership and party protections.
- Configurable hunter sale and equipment level/rank upgrades with saved results and inventory receipts. Original prices remain missing, so these transactions require explicit configuration and stay unavailable by default.
- Explicit Gem inventory and free initial mounting into empty equipment slots, including saved placements and exact 64-bit Gem IDs. Requires supplied Gem references and inventory; no Gems are automatically granted. Paid removal, transfers, recruitment and upgrades remain unsupported.

## Improved

- Hunter Library navigation and material-backed character references, with original equipment names, artwork mappings and recovered skill evidence.
- Source-verified monster artwork ownership and optional historical material stat projections. Historical observations remain separate from final-version balance.
- Recovered Guild, skin, quest, fishing and story-journal contracts now document their remaining data gaps. These areas are still incomplete; fishing settlement and playable Mirage encounters remain unavailable.
- Prepared resource profiles for Episode 7, expanded hunters, Guild artwork and Gems, with their original binary resources included in the bundle. These profiles remain inactive by default and their native gameplay validation remains pending.

## Fixed

- Campaign return and persisted progress handling, plus native Fight Club honor display metadata.
- Friend-removal retries, social ownership checks and stale relationship updates.
- Equipment name lookup and native upgrade receipts, including absolute inventory quantities.
- Gem slot numbering, equipment-rank checks for second slots, retry receipts and precision loss for identifiers above JavaScript's safe-integer range.

Equipment and Gem transactions have been checked against the reconstructed server protocol; their native menus and combat effects still need client validation. Revival remains ongoing, with original balance, reward tables and portions of the economy still missing.
