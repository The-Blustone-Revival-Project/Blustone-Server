# Blustone Server 1.2.0

This release adds a verified resource installer and expands local gameplay and recovered-content support. Existing saves and the default Episode6 profile (139 packages) remain supported. Run `npm ci`, `npm run setup`, `npm run build`, then `npm start`; setup also accepts an offline copy of the resource ZIP and preserves existing saves.

When upgrading, preserve your existing state file, selected profile and runtime options.

The validated client path uses the separate Instrumented build. A stock APK redirected through a proxy is not yet verified equivalent. Asset installation does not resolve every native assertion, including the separately investigated empty-value database-write report.

## Added

- One-command installation of the pinned original resources, including offline import, checksum verification, interruption-safe writes and protection against replacing differing files. Git checkouts and container images still require these resources; Docker Compose mounts the imported host directory.
- Optional local Guild creation, membership, invitations, management, donations and encrypted Guild/public-channel text chat. Guild fuel requests and support records track configured contribution without claiming the still-unrecovered AP payout.
- Optional timed Expedition dispatch, pass-entitled instant dispatch, and configured paid individual or whole-job finishes, with persistent jobs and claim handling. Original reward, entitlement and pricing data remain incomplete.
- Configured local Mirage floors, carried parties, first aid, revival and re-entry, plus an optional local fishing catch lifecycle and one-time tutorial settlement. These require explicit local policies; original floor assignments, fishing pools and balance are not recovered.
- Optional profile editing, owned Veteran-ticket gifting, resource exchanges, dorm expansion and additional supplied Gem workflows. Missing original economic tables are not replaced with unrestricted rewards.

## Improved

- Original later-Episode art, dialogue, voices, cut-ins and combat dependencies are available in an inactive280-package preparation, including linked battle continuations through Episodes11–18. Resource coverage does not grant story clears, complete rewards or prove native playthroughs.
- Expanded material-backed Hunter Library coverage, with opt-in adoption of23 exact scripted Episode skill graphs, historical stat projections and selective community birth grades. These preserve their recovered-versus-local distinctions; absent skills and unknown ordinary balance remain explicit.
- Fight Club defense preparation, local standings and owned-party profile data, plus original UI artwork for Guild, Mirage and fever areas. Real-peer ranked play and broader game-mode completeness remain unfinished.
- Optional resource snapshots keep package bytes and manifests consistent for an app lifetime and avoid rebuilding the same resource content for every request.

## Fixed

- Fresh-install instructions now install resources before verification and no longer require private migration saves. Unconfigured direct execution refuses instead of silently serving a minimal protocol fixture; supported startup uses the named-profile launcher.
- Failed Mail and Supply saves now roll back in-memory flags, deletion records, rewards and resource clocks. Activity rewards also respect the native AP quantity and charge-time limits.
- Episode wallet receipts preserve client Manda quantities, and fishing catch receipts place inventory changes under the native parser's correct parent.
- Resource range/conditional handling, dispatch receipt replay and several inventory/progression transitions now preserve their committed state across retries and storage failures.

Experimental profiles remain inactive by default. Original rewards, equipment/Gem tables, GvG seasons and portions of the economy are still missing. Later-area boot, memory use, rendering and many combat effects still need native validation; this release does not claim complete original-game functionality.
