# Blustone Server 1.0.0

The first public release of the BLUSTONE revival server. Run the game against a locally hosted server, explore its village and campaign, play recovered Episode stories, and keep your hunters and progress between sessions.

## Game features

- **Village and expedition travel:** enter the village, visit the Airport, travel to expedition areas, choose a stage, prepare a party, and return to the map after battle.
- **Campaign battles and progression:** battle results, stage stars, area unlocks, hunter/team experience, and earned rewards are saved. The campaign includes the recovered identifiers for all 50 expedition stages; enemy encounters and difficulty still use local reconstruction.
- **Episode stories:** original chapter and story navigation, dialogue, story maps, battle links, and read/clear progress. Episodes 1–5 have been played through in the native client; Episode 6 includes recovered story and combat material, with progression still incomplete.
- **Hunter roster and parties:** hunter inventory, character book, party selection, training, rank-up, and skill-training support. Owned hunters and party selections persist between sessions.
- **Fight Club arena:** opponent preparation, battles, victory results, and saved honor/rating progression. Attack and defense parties are separate. Opponents, prices, and rewards currently follow local server rules.
- **Recruitment and hunter collection:** Search capsules, hunter traces, recruitment, trace exchange, helper selection, and repeat-search support.
- **Rewards and inventory:** login bonuses, mail, Special Supply, items, currencies, and supported campaign/Episode rewards.
- **Saved accounts and progress:** local login and persistent saves retain your roster, parties, items, story progress, and earned rewards when the server restarts.

## Recovered game content

- Original Episode chapter/story data, dialogue references, battle connections, and reward identifiers.
- Hunter identity and equipment-name records, recovered skill text and symbolic formulas, and documented role/element metadata.
- Campaign stage identifiers and environment/background definitions recovered from the client.
- Original artwork, UI layouts, battle backgrounds, character animations, voices, and cut-ins for the included content.
- A resource bundle covering the current Episode 6 profile, with **139 downloadable packages**, including village, campaign, Episode, and Fight Club material.

## Current limitations

Revival is ongoing. Original server-side balance, stat growth, reward mappings, and parts of the economy are not fully recovered. Some values use explicitly documented local rules or historical-stat projections. The included content does not represent the complete original game.

- Episode 6 progression is incomplete; later Episode content is not part of the active release profile.
- Fishing catches and settlement, playable Mirage encounters, and jewel gameplay remain unreconstructed.
- Arena matchmaking and economy are local approximations.
- Some artwork and reward thumbnails are still missing.

## Getting started

1. Clone the Server repository and check out `v1.0.0`.
2. Run `npm ci`.
3. Download `Blustone-Server-Resources-1.0.0.zip` from this release and import it with `python scripts/resources/bundle.py import <file>`.
4. Run `npm run build`, then `npm start`.
5. Use the [BLUSTONE Instrumented client](https://github.com/The-Blustone-Revival-Project/Blustone-Instrumented/releases/latest) to connect to the local server.

The default client address is `http://10.0.2.2:8080` for BlueStacks/Android Emulator. Saves are stored locally in `var/state.json`; preserve that file when upgrading.
