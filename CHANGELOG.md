# Changelog

Release descriptions focus on game features and recovered content. The first public release introduces the available game; later versions describe changes from that public baseline.

## 1.0.0 — 2026-10-10

### Game features

- Village and expedition travel, campaign battles, stage stars, progression and saved rewards.
- Recovered Episode stories, hunter roster/party management, recruitment and Fight Club arena.
- Local accounts, inventory, currencies and progress that persist between sessions.

### Recovered game content

- Episode/story data, campaign identifiers, hunter identities and skill references.
- Original art, dialogue, voices, animations and battle/UI resources for the included content.

See [the full 1.0.0 introduction, limitations and setup](releases/1.0.0.md).
