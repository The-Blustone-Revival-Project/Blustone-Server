# Changelog

Release descriptions focus on game features and recovered content. The first public release introduces the available game; later versions describe changes from that public baseline.

## 1.2.0 — 2026-10-26

- Added verified resource installation and explicit local Guild/chat, dispatch, Mirage, fishing and progression workflows.
- Expanded optional original Episode resource coverage and source-pinned Hunter skill/stat/birth projections, while preserving their experimental limits.
- Fixed clean-install guidance, unconfigured executable startup, Mail/Supply rollback, and native wallet/inventory receipt consistency.
- Existing saves and the default139-package profile remain supported; stock-APK equivalence and broader native validation remain incomplete.

See [the full1.2.0 changes and limitations](releases/1.2.0.md).

## 1.1.0 — 2026-10-11

- Added persistent local-account friendships and Likes, bulk rank-up, and explicitly configured hunter sale, equipment upgrades and initial Gem mounting.
- Improved Hunter Library references, original equipment localization and monster artwork ownership.
- Fixed social retries, campaign return, equipment receipts and exact 64-bit Gem identifiers.
- Existing saves and the default 139-package Episode 6 profile remain compatible. Original equipment/Gem tables and native gameplay validation remain incomplete; prepared expanded profiles remain inactive.

See [the full 1.1.0 changes and limitations](releases/1.1.0.md).

## 1.0.0 — 2026-10-10

### Game features

- Village and expedition travel, campaign battles, stage stars, progression and saved rewards.
- Recovered Episode stories, hunter roster/party management, recruitment and Fight Club arena.
- Local accounts, inventory, currencies and progress that persist between sessions.

### Recovered game content

- Episode/story data, campaign identifiers, hunter identities and skill references.
- Original art, dialogue, voices, animations and battle/UI resources for the included content.

See [the full 1.0.0 introduction, limitations and setup](releases/1.0.0.md).
