The 2026-10-11 web pass found a Korean community description with six fish
names in an increasing ordinary-grade value order: 뼈살이 빙어, 흰수염 메기,
메트론 은어, 칼날 뱀장어, 짝발 민물게, 은쟁반 가지미.
Source: [read-only community wiki](https://www.readonly.wiki/w/%EB%B8%94%EB%A3%A8%EC%8A%A4%ED%86%A4).
These are community display-name candidates, not canonical item identifiers.
The source does not establish the client version, exact prices, grade
thresholds, length distribution, bait pool or original GetItem rows. Its
mirrors are copies of the same account, not independent corroboration.

The text also describes size-associated silver/gold crowns and occasional
non-fish upgrade materials. This can guide a future visual capture search;
it cannot set a drop rate or manufacture material rewards. Keep provenance
separate from the original final-client parser.

The immutable final-client NPC0004 English dialogue already supplies the
literal Calcium Smelt display name (DataDump fishing-item-identity-candidates).
The Korean smelt candidate is a possible semantic join, not a recovered
localization pair. No Korean name above is assigned to FS001..FS011, a fish_id,
an item ref_id or a guaranteed tutorial catch.

indexed matching source in this pass. Broader publisher-domain and video
queries mainly returned app descriptions, rather than usable in-game frames
or server data. Two dated Reddit fishing leads were indexed, but direct page
retrieval failed: [2021 catch post](https://www.reddit.com/r/Blustone/comments/lhd4rn/)
and [2021 update discussion](https://www.reddit.com/r/Blustone/comments/mghsm1/).
